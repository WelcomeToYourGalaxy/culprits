# Alegreya (Mother Earth basemap, round 162m)

Alegreya and Alegreya Italic by Huerta Tipográfica (The Alegreya Project
Authors), under the SIL Open Font License 1.1 (Alegreya-OFL.txt), from
github.com/google/fonts (ofl/alegreya).

- `Alegreya.ttf`, `Alegreya-Italic.ttf`: the variable fonts, unchanged, for
  the Mother Earth basemap's note box.
- `Alegreya-Medium/`, `Alegreya-MediumItalic/`: the same fonts at weight 500
  cut into MapLibre's letter files (signed distance fields, 24 px, buffer 3,
  radius 8), ranges 0-8959, for that basemap's place names (round 162m).
