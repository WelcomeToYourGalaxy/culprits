# Map glyphs

Signed-distance glyphs for MapLibre, made from EB Garamond (Regular, SemiBold
at weight 600, Italic), SIL Open Font License 1.1 (OFL.txt). Used by the Old
fantasy painting basemap's place names (round 162b). Ranges cover Latin,
Latin Extended, Greek, Cyrillic, Vietnamese and general punctuation; 24 px,
3 px buffer, radius 8, cutoff 0.25 (as MapLibre expects).
