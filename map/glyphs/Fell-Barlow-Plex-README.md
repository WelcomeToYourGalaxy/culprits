# IM Fell English, Barlow Semi Condensed, IBM Plex Mono (round 167p)

Cut into MapLibre's letter files (signed distance fields, 24 px, buffer 3,
radius 8, cutoff 0.25), ranges 0-8959 and 65280-65535, from the fonts in
github.com/google/fonts, each under the SIL Open Font License 1.1:

- `IMFellEnglish-Regular/`, `IMFellEnglish-Italic/`, `IMFellEnglishSC-Regular/`:
  the Fell Types, revived by Igino Marini (IMFellEnglish-OFL.txt). The
  Painted atlas's place names.
- `BarlowSemiCondensed-Regular/`, `-Medium/`, `-Italic/`: Barlow by Jeremy
  Tribby (BarlowSemiCondensed-OFL.txt). The Satellite imagery basemap's names.
- `IBMPlexMono-Regular/`, `-Medium/`, `-Italic/`: IBM Plex Mono by IBM
  (IBMPlexMono-OFL.txt), the hologram's own typeface. The hologram's names.

IM Fell English has no Greek or Cyrillic letters; names are asked for in
English first, then in Latin letters.
