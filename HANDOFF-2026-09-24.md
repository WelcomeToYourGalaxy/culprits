## How work reaches the site

The Commander runs everything locally and pastes one command at a time (zsh, so
no `#` comments in terminal steps). This sandbox cannot push. Each round is one
Python patch script: a checked diff applied by exact-text match, refusing to run
twice and exiting 0 when already applied. The Commander downloads it, runs it
from the repo root, runs both test files, then commits and pushes. The website
updates a minute or two after the push; the browser caches hard, so check with
Cmd+Shift+R.

**2. Cerulean points have not been built.**
`pipeline/cerulean/harvest_points.py` downloads every slick (1,322,315 records)
and every slick source as a point, and tiles them into
`map/tiles/cerulean_slick_points.pmtiles` and `cerulean_source_points.pmtiles`.
Until those files exist, the two Cerulean layers behave as before: shapes from
zoom 6, shaded count squares wider out, sources only over a small area.

The first version of this script saved every field, including `centerlines` —
a traced outline per slick — which is what filled the disk. It now keeps only
each record's id and position, pages by id (deep pages by offset timed out at
10,000), and tiles only to the zooms the map shows. The map reads the whole
record live from Cerulean when a point is clicked.

Needs tippecanoe and a few hundred MB free. It is resumable; state sits in
`data/cerulean/*.state.json`. If it warns that a file is over 95 MB, GitHub
Pages will refuse it and it needs splitting or hosting elsewhere.

    python3 pipeline/cerulean/harvest_points.py
    git add map/tiles/cerulean_*_points.pmtiles && git commit -m "Cerulean points" && git push

## Working practices that held up

- Run it in a real browser before calling it fixed. The news marks were being
  drawn under the painted plate, and nothing but a browser showed it.
- When the live source is unreachable from the sandbox, say so and ask for the
  panel line rather than shipping a guess.
- One command per paste, `git pull` first, a clean-copy run of every patch
  before it is sent, and every patch safe to paste twice.
- No orange or yellow, no neon, earthy and muted. No editorial filtering: every
  row a source publishes is carried, and what cannot be drawn is counted and
  stated. Plain explanations for a novice, short.
